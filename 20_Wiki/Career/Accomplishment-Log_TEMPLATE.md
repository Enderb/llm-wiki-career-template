# Accomplishment Log

A running, date-stamped record of career accomplishments distilled from raw career inputs (feedback, project notes, kudos, and reflections). This is the **single source of truth** for resume content. Maintained by AI agents via **Workflow D**; do not hand-edit.

## Entry Format

Each entry uses a condensed STAR structure:

```
- **YYYY-MM-DD | [Entity/Project]** — [Action verb] + [Task/Context], leading to [Measurable Result]. [Optional: situation/obstacle + tags]
```
