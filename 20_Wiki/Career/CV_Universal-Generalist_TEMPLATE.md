# CV — Universal (Cold Applications)

> General-purpose CV for applications where no target posting or tailored CV exists. Derived strictly from [[Master_CV]], [[LinkedIn_Profile]], and the [[Accomplishment-Log]]. Balances full-stack web, developer tooling, ML/AI, and research signals so it holds up across most engineering postings.
> Live compiled baseline: [[Living-Resume]] · Frozen baseline: [[Master_CV]]

## When to Use This Instead of a Tailored CV

- **Use:** cold outreach, speculative applications, networking, portfolio pages, and postings without a detailed JD.
- **Not a substitution:** each role-specific page under `20_Wiki/Career/Applications/[Company]/` re-ranks the same facts for a specific team. When a posting exists in `10_Raw/Job-Postings/`, prefer a tailored CV — a targeted CV converts better than a generalist one.
- **ATS note:** this version should be keyword-balanced, not keyword-peaked. If a posting names a specific stack, swap the skills order to lead with it.
